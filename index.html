Tải Về File Live ISO (Mới Nhất)

Màn Hình Giao Diện Dự Kiến

DuyKhanhOS Desktop Environment (XFCE4 + Plank)

Môi trường Auto-Login thẳng vào màn hình làm việc

Tính Năng Cốt Lõi

🚀 Hiệu Năng Siêu Tốc

Nhân Linux tinh giản kết hợp với bộ swap ảo 2GB giúp hệ thống vận hành cực kỳ mượt mà trên cả các dòng máy tính cũ cấu hình yếu.

🖥️ Giao Diện Hiện Đại

Tích hợp thanh Dock Plank mượt mà mô phỏng trải nghiệm ứng dụng cao cấp. Khởi động đồ họa Plymouth có chữ DuyKhanhOS cá tính.

📶 Kết Nối Wi-Fi Trực Quan

Nhận diện card mạng Wi-Fi tự động ngay khi boot đĩa Live CD. Hỗ trợ click chuột chọn điểm kết nối hoặc NMCLI nâng cao.

💿 Trình Cài Đặt To SSD

Menu boot phân tách rõ ràng 2 luồng: Chạy thử kiểm tra phần cứng hoặc nạp vĩnh viễn vào bộ nhớ SSD máy thông qua Calamares. Tự nhắc rút USB khi cài xong.

Thông Số Kỹ Thuật Đóng Gói

Kiến trúc hệ thống 64-bit (x86_64 / amd64)
Môi trường máy bàn XFCE4 Custom (Mac layout)
Dung lượng file nén Khoảng 2.0 GB – 2.5 GB (N nén XZ đa luồng)
Ứng dụng đi kèm sẵn Firefox, VLC Media Player, LibreOffice, Mousepad, Git, Trình quản lý mạng
Bộ gõ Tiếng Việt Fcitx / Fcitx-Unikey mặc định khởi động cùng hệ thống
Yêu cầu thiết bị flash Ổ cứng USB dung lượng từ 4GB, 8GB, 16GB hoặc 32GB (Flash qua phần mềm Rufus)
